# Destiny Wheel Custom Picker

Add custom items to a canvas-drawn spin wheel with proportional colored segments, weighted probabilities, and a confetti celebration on each winner.

## Features
- Add up to 20 items with individual weight (1–5) making segments proportionally larger
- Canvas wheel with smooth ease-out deceleration animation on each spin
- Confetti burst animation on winner announcement
- "Remove winner after spin" toggle to eliminate items from the pool
- Spin history showing the last 10 results with timestamps, persisted in localStorage

## Usage
Type an item name, set its weight with the slider, and click Add. Click Spin to rotate the wheel. The pointer on the right side marks the winner. Enable the toggle to remove winners automatically for elimination-style decisions.
